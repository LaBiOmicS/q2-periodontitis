# Step-by-Step Tutorial: `q2-periodontitis`

This tutorial guides you through analyzing a subgingival biofilm 16S rRNA dataset using `q2-periodontitis` in QIIME 2 (amplicon distribution 2024.10).

---

## 🛠️ Step 1: Input Data Requirements

To run `q2-periodontitis`, you need two standard QIIME 2 artifacts:
1. **Feature Table (`FeatureTable[Frequency]`):** ASV/OTU count frequencies across your samples.
2. **Taxonomy (`FeatureData[Taxonomy]`):** taxonomic assignments generated by any classifier (e.g., `q2-feature-classifier` with eHOMD, SILVA, Greengenes2, GTDB, or `q2-consensus-taxonomy`). If the taxonomy has a `Confidence` column, you can filter low-confidence assignments with `--p-min-confidence`.

For the longitudinal and statistical steps you also need a **sample metadata** file, for example:

```text
sample-id	PatientID	Visit	Status
#q2:types	categorical	categorical	categorical
P1-BL	P1	Baseline	periodontitis
P1-SRP	P1	Post-SRP	treated
P2-BL	P2	Baseline	periodontitis
P2-SRP	P2	Post-SRP	treated
```

---

## 🧪 Step 2: Collapse Features into Socransky Complexes & Compute Dysbiosis Indices

```bash
qiime periodontitis collapse-complexes \
  --i-table feature-table.qza \
  --i-taxonomy taxonomy.qza \
  --p-assignment-mode genus-majority \
  --p-min-confidence 0.7 \
  --p-pseudocount 1e-5 \
  --p-keystone-threshold 0.005 \
  --p-keystone-steepness 1.0 \
  --o-complex-table socransky-complexes.qza \
  --o-indices dysbiosis-indices.qza \
  --o-mapping feature-socransky-map.qza
```

- `--p-assignment-mode strict` assigns only species-level matches; `genus-majority` (default) uses the species when available, otherwise the genus-level mapping.
- Features with `Confidence < --p-min-confidence` are reported as `Other` (`low-confidence`); the default `0.0` disables the filter.

### Optional: custom reference
To add or override taxon → complex assignments, write a TSV with a `taxon` and a `complex` column and import it as `SocranskyReference`:

```bash
printf 'taxon\tcomplex\nSelenomonas noxia\tExtended\n' > my-reference.tsv
qiime tools import --type SocranskyReference \
  --input-path my-reference.tsv --output-path my-reference.qza

qiime periodontitis collapse-complexes \
  --i-table feature-table.qza \
  --i-taxonomy taxonomy.qza \
  --i-custom-mapping my-reference.qza \
  --o-complex-table socransky-complexes.qza \
  --o-indices dysbiosis-indices.qza \
  --o-mapping feature-socransky-map.qza
```

### Outputs Explained:
- `socransky-complexes.qza` (`SocranskyComplexes`): relative abundance of the 8 ecological complexes in each sample (each row sums to 1).
- `dysbiosis-indices.qza` (`PeriodontalIndices`): $pMDI$, $pMDI_{\text{ilr}}$, $SWL$ and $KRS$.
- `feature-socransky-map.qza` (`SocranskyMapping`): how each ASV was assigned (original taxonomy, complex, resolution, confidence). Inspect it with:

```bash
qiime metadata tabulate \
  --m-input-file feature-socransky-map.qza \
  --o-visualization feature-socransky-map.qzv
```

## 📈 Step 3: Interactive Dashboard Generation (`summarize`)

```bash
qiime periodontitis summarize \
  --i-complexes socransky-complexes.qza \
  --i-indices dysbiosis-indices.qza \
  --i-mapping feature-socransky-map.qza \
  --m-metadata-file sample-metadata.tsv \
  --o-visualization periodontitis-report.qzv
```

With metadata, every index is compared across the groups of each categorical column (Mann-Whitney U or Kruskal-Wallis) and the report shows *p*- and Benjamini-Hochberg *q*-values. The report embeds its JavaScript libraries, so it also works offline.

```bash
qiime tools view periodontitis-report.qzv
```
Or upload `periodontitis-report.qzv` to [view.qiime2.org](https://view.qiime2.org).

## 🔄 Step 4: Longitudinal Treatment Delta Analysis (`delta-indices`)

For paired clinical data (e.g., Baseline vs. Post-SRP):

```bash
qiime periodontitis delta-indices \
  --i-indices dysbiosis-indices.qza \
  --m-metadata-file sample-metadata.tsv \
  --p-subject-col PatientID \
  --p-group-col Visit \
  --p-baseline-group Baseline \
  --p-target-group Post-SRP \
  --o-delta-table delta-indices.qza
```

The resulting `delta-indices.qza` (`SampleData[PeriodontalIndicesDelta]`) contains $\Delta pMDI$, $\Delta pMDI_{\text{ilr}}$, $\Delta SWL$ and $\Delta KRS$ (target minus baseline) for each patient. **Its rows are indexed by subject ID**, not by sample ID.

- Numeric time columns work too (e.g., `--p-group-col Week --p-baseline-group 0 --p-target-group 12`).
- Each subject must have at most one sample per group; otherwise the command fails and lists the duplicated subjects.
- If no subject has both groups, the command fails instead of producing an empty table.

```bash
qiime metadata tabulate \
  --m-input-file delta-indices.qza \
  --o-visualization delta-indices.qzv
```
