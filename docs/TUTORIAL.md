# Step-by-Step Tutorial: `q2-periodontitis`

This tutorial guides you through analyzing a subgingival biofilm 16S rRNA dataset using `q2-periodontitis` in QIIME 2.

---

## 🛠️ Step 1: Input Data Requirements

To run `q2-periodontitis`, you need two standard QIIME 2 artifacts:
1. **Feature Table (`FeatureTable[Frequency]`):** A `.qza` artifact containing ASV/OTU count frequencies across your samples.
2. **Taxonomy (`FeatureData[Taxonomy]`):** A `.qza` artifact containing taxonomic assignments generated by any classifier (e.g., `q2-feature-classifier` with eHOMD, SILVA, Greengenes2, or `q2-consensus-taxonomy`).

---

## 🧪 Step 2: Collapse Features into Socransky Complexes & Compute Dysbiosis Indices

Run the `collapse-complexes` command:

```bash
qiime periodontitis collapse-complexes \
  --i-table feature-table.qza \
  --i-taxonomy taxonomy.qza \
  --p-assignment-mode genus-majority \
  --p-keystone-threshold 0.005 \
  --p-keystone-steepness 1.0 \
  --o-complex-table socransky-complexes.qza \
  --o-indices dysbiosis-indices.qza \
  --o-mapping feature-socransky-map.qza
```

### Outputs Explained:
- `socransky-complexes.qza` (`SampleData[SocranskyComplexes]`): Relative abundance matrix of the 8 ecological complexes across all samples.
- `dysbiosis-indices.qza` (`SampleData[PeriodontalIndices]`): Calculated values for $pMDI$, $pMDI_{\text{clr}}$, $SWL$, and $KRS$.
- `feature-socransky-map.qza` (`FeatureData[SocranskyMapping]`): Mapping table tracking how each ASV was assigned.

---

## 📈 Step 3: Interactive Dashboard Generation (`summarize`)

Generate the interactive visual report (`.qzv`):

```bash
qiime periodontitis summarize \
  --i-complexes socransky-complexes.qza \
  --i-indices dysbiosis-indices.qza \
  --i-mapping feature-socransky-map.qza \
  --m-metadata-file sample-metadata.tsv \
  --o-visualization periodontitis-report.qzv
```

View the report locally:
```bash
qiime tools view periodontitis-report.qzv
```
Or upload `periodontitis-report.qzv` to [view.qiime2.org](https://view.qiime2.org).

---

## 🔄 Step 4: Longitudinal Treatment Delta Analysis (`delta-indices`)

For paired clinical trial data (e.g., Baseline vs. Post-Treatment SRP):

```bash
qiime periodontitis delta-indices \
  --i-indices dysbiosis-indices.qza \
  --m-metadata-file sample-metadata.tsv \
  --p-sample-id-col PatientID \
  --p-group-col Visit \
  --p-baseline-group Baseline \
  --p-target-group Post-SRP \
  --o-delta-table delta-indices.qza
```

The resulting `delta-indices.qza` contains $\Delta pMDI$, $\Delta SWL$, and $\Delta KRS$ for each patient.
